# Capture domain language

- **Profile identity:** The display name and photo that the person adds. Capture never infers either value.
- **Profile reading:** Capture derives the current recurring threads from the record. It can regenerate this reading.
- **Landed point:** This mark states that Capture formed the profile reading from a record. It does not verify identity.
- **Cloud access:** Current permission to use Capture Cloud, supplied by either a current paid entitlement or a current complimentary grant.
- **Complimentary grant:** Service-managed Cloud access for one authenticated owner UUID. It is independent of billing and is not a subscription.
- **Routing plan:** A complete, pre-write proposal that accounts for one capture's source and names the intended result for each atomic item. It is not permission to mutate the Board.
- **Atomic capture item:** One model-declared Action, developing thought, Intention, supporting context, or deadline that owns an exact portion of the capture source.
- **Unresolved item:** An exact source portion the planner declines to route because its meaning or destination remains ambiguous. It must stay pending rather than being coerced.
- **Planned settlement:** The one atomic Board transition that may consume a validated Routing plan while its capture identity is still pending and has no prior settlement.
- **Partial unresolved remainder:** The exact unresolved source runs left pending under the original capture identity after the understood items settle. It is not a second capture.
- **Manual settlement:** One atomic Board transition that consumes the exact pending capture revision into the destination the person explicitly chose. It is permanently authoritative over model work for that capture.
- **Temporary Thread title:** A clearly provisional label made mechanically from an offline capture’s opening words. It is renameable display text, not semantic routing context or a learned correction.
