# Capture domain glossary

- **Thread** — a living note whose fragments accumulate over time.
- **Fragment** — one dated piece of source material inside a thread.
- **Fold** — a user-approved consolidation in which a source thread stops being active and its fragments join a destination thread. A fold retains the source thread's identity and wording so it can be restored.
- **Folded source** — the retained snapshot of a source thread after a fold. It is history, not an active thread.
- **Restore a fold** — recreate a folded source as an active thread and return its original fragments to it.
- **Sync merge** — reconciliation of board copies from different devices. It is distinct from a user-approved thread fold.
